          💬 Messaging sequences

          Named, reusable presets for Instagram's first message and phase1/2/3 follow-up steps — since your messaging keeps changing, edit these instead of digging through code. Assign one to each account above.

          Follow-up sequence (LinkedIn)

          Timing is days since the phase started. {naam} becomes the lead's first name, {link} your calendar link. Each step's wording is composed from several phrasings, so leads due for the same step at the same time don't all get the identical nudge. Instagram's follow-up sequence now lives per Messaging sequence above.

          Also supports spintax — write {option one|option two} in a message and one option is picked at random each time it's sent. Example: {Hey|Hi} {naam}, {just checking in|following up}. Nesting works too.

          Daily limit ramp curve

          One row per day the limit changes, each timed as "+N days after the previous row" — it holds steady until then, and forever after the last row. Day 1 at 0 is what "warmup" is.

          In-session pacing pattern

          Drag to reorder. Loops back to the top once it reaches the end, for as long as a sending session runs.

          For a session whose volume is too low to ever naturally hit the send-block threshold above (e.g. warming up, or a small daily goal) — forces one pause in right before the session ends, so you're never just opening Instagram to send and immediately closing it again. Only applies to a session where at least one message was actually sent.

          Messaging sequences

          No sequences yet — click "+ New" to create one.

          First message

          {naam} becomes the lead's first name. Up to 4 opening-line variants — a fresh lead randomly gets one, and which one it got is tracked, so Analytics' "Opener A/B test" tab can show which wording actually performs best.

          Each variant also supports spintax for extra wording variety within itself (on top of the A/B variants) — write {option one|option two|option three} and one option is picked at random every time. Example:
          {Hey|Hi} {naam}, {have you seen|did you catch} my video yet? 👀
          Combine as many as you like in one message, and they can nest too, e.g. {Hey{,| there,}|Hi}. Don't use this for {naam}/{views}/{months} — those stay as plain placeholders, not spintax (no | inside them).

          Follow-up steps

          Each step timed as "+N days after the previous step in this phase" — same idea as the Timing sequence ramp curve.

          Also supports spintax — write {option one|option two} and one option is picked at random each time it's sent (a fresh roll every send, not locked per lead like the opener variants above). Example: {Hey|Hi} {naam}, {just checking in|following up} — {have you seen it yet?|any thoughts?}
